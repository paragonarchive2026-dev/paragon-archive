What this tool can and cannot do

Works here (on-device)

  • Raster image convert: PNG / JPEG / WebP via canvas
  • Resize by max width/height
  • Text download and open plain text files

Not faked in v1

True multi-PDF merge, Office conversion, video/audio transcode, and HEIC on every browser need native codecs or a server. This build will not pretend those finished — use a desktop tool or wait for a future free WASM engine if we add one.
